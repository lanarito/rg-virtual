Clave de Google

Se guarda solo en este dispositivo. No queda en el código ni en GitHub.

Cómo crear la clave (una sola vez)
  1. Entrá a console.cloud.google.com con tu cuenta de Google y creá un proyecto (por ejemplo "rg-virtual").
  2. Activá la facturación. Google la pide aunque no cobre: hay un uso mensual gratis que alcanza de sobra para un prototipo.
  3. En APIs y servicios → Biblioteca habilitá Maps JavaScript API (Street View) y Map Tiles API (ciudad 3D).
  4. En APIs y servicios → Credenciales tocá Crear credenciales → Clave de API y copiala.
  5. Restringila: en Restricciones de aplicación elegí Sitios web y agregá https://lanarito.github.io/*, https://localhost:*/* y la IP de tu compu (por ejemplo https://192.168.0.10:*/*). En Restricciones de API dejá solo las dos de arriba.
  6. Opcional: en Cuotas poné un límite diario bajo, para estar tranquilo.

Narración

Los audios están en assets/audio/, uno por lugar. Si cambiás un texto en data/pois.json, regeneralos con python tools/generar-audios.py . — o grabá tu propia voz y reemplazá el mp3.

Paseo

Para probar el modo paseo sin salir de casa, abrí mapa.html?simular=1 y tocá el mapa para "caminar".
